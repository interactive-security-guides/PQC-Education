00
THE CLASSICAL WALL
RSA security rests entirely on one hard problem. Classically, it holds. Quantum breaks it completely.
THE LOCK
RSA-2048
The RSA public key is a number N = p × q, where p and q are large primes. Knowing p and q instantly reveals the private key.

RSA-2048 uses N with 617 decimal digits. Multiplying p × q is trivial. Working backwards to find them is — classically — impossible.
CLASSICAL ATTACK
O(exp(∛(64/9 · ln N · (ln ln N)²)))
This means: the time to crack RSA grows faster than any polynomial — but Shor’s algorithm slashes that to a manageable curve.
The best classical algorithm is the General Number Field Sieve (a highly optimized mathematical sieving method) — sub-exponential, but still astronomical at 2048 bits.

Required operations: ~1060.
At a trillion ops/sec: ~300 trillion years.
THE QUANTUM PATH
O((log N)³)
Big-O notation: time grows gently as the key gets longer — doubling the key only increases run time by 8×. Key size offers no refuge against Shor’s.
Shor's algorithm (Peter Shor, 1994) reduces factoring to polynomial time on a quantum computer.

The insight: don't search for the factors. Instead, find the hidden mathematical period in the problem — it hands you the factors directly.
CLASSICAL COMPLEXITY
sub-exponential — grows faster than polynomial
Sub-exponential = still grows extremely fast, but slower than pure exponential. Adding bits to the key makes it harder — but quantum eliminates the advantage entirely.
SHOR'S ALGORITHM COMPLEXITY
O((log N)³) — polynomial in key length
Doubling the key length only increases quantum run time by a factor of 8. No key size is safe.
FOLLOW THIS EXAMPLE THROUGH ALL 6 STEPS
To make the math concrete, each step will trace a small working example: N = 3,233 (the number to factor), a = 2 (a randomly chosen starting number). The goal: find the hidden prime factors 61 × 53 using only quantum operations.

RSA-2048 uses numbers with 617 digits — this 4-digit example shows the same structure in a form you can verify by hand.
02
SUPERPOSITION — ALL VALUES SIMULTANEOUSLY
A quantum register is placed in superposition, holding every possible input value at the same time
QUANTUM REGISTER
Each qubit is placed into superposition using Hadamard gates:
|0⟩ → (|0⟩ + |1⟩) / √2
Quantum notation: a qubit starts at 0. After the Hadamard gate operation, it becomes equally likely to be 0 or 1 — but holds both possibilities until measured.
With n qubits, the register holds 2n states simultaneously. For RSA-2048, Shor's needs roughly ~4,096 logical qubits — representing 101,233 values at once.
|ψ⟩ = (1/√2n) × Σ|x⟩ for x = 0 … 2n−1
All 2n possible input values are held simultaneously, each with equal probability. For our example: the register holds every value from 0 to 2n−1 at once — the oracle will process them all in a single operation.
NOT PARALLELISM
A classical bit is 0 or 1 — checked one state at a time. A qubit in superposition is 0 and 1 simultaneously — a fundamentally different representation of information.

This isn't "checking many values at once." It's encoding all values into a single quantum state — and processing that state as a whole.
03
ORACLE — THE PERIODIC FUNCTION
f(x) = ax mod N is applied to the entire superposition simultaneously — revealing a hidden period
THE PERIOD r
The function f(x) repeats with a hidden period r: f(x + r) = f(x) for all x.

Once r is known, classical Euclidean GCDs yield the factors immediately:
gcd(ar/2 + 1, N) = p    gcd(ar/2 − 1, N) = q

GCD = Greatest Common Divisor — a classical algorithm thousands of years old (Euclid’s) that runs in milliseconds and extracts the prime factors once r is known. For our example: r = 6 gives p = 61, q = 53.
QUANTUM PARALLELISM
The quantum oracle is a black-box quantum subroutine that processes all inputs at once — not sequentially. It computes f(x) for every value of x simultaneously because the input register is in superposition.

One quantum gate operation maps the entire superposition to its outputs. Input and output registers become entangled.
ENTANGLEMENT
Entanglement means the input and output registers are now mathematically linked — knowing something about one instantly tells you something about the other.

After the oracle, the quantum state encodes the full relationship between every x and its f(x) simultaneously. The periodic structure is now encoded in the entangled quantum state.

Classically: computing f(x) for all 101,233 inputs would take longer than the age of the universe. Quantum: one operation.
04–05
QUANTUM FOURIER TRANSFORM — EXPOSING r
The QFT converts the periodic quantum state into frequency domain — measurement then reveals r COVERS PIPELINE STAGES 04 + 05
FREQUENCY SPECTRUM AFTER QFT
y: probability of outcome ↑ each bar = a possible period — peaks appear at multiples of 1/r x: frequency →
CONSTRUCTIVE INTERFERENCE
Probability amplitudes — quantum values whose squares give the likelihood of each outcome — cancel everywhere except at multiples of 1/r, where they add up constructively.

Measuring the register returns an integer m at a frequency peak. Classical continued fraction expansion then recovers r exactly — like GPS triangulation: an imprecise measurement worked backwards to a precise answer, in milliseconds.

For our example: measurement returns m = 21,845. Continued fraction expansion works backwards to find r = 6.
WHAT IS THE QFT?
Just as a prism splits white light into its color spectrum, the Quantum Fourier Transform splits the quantum state into its frequency components — revealing the hidden period r as a sharp peak in the spectrum.

Classical FFT: O(n log n) on n samples.
QFT: O(n²) quantum gates — which seems slower, but the QFT operates on an exponentially large quantum state that would require 2n classical operations just to describe. The comparison is not apples to apples.
WHY THIS WORKS
The periodic structure of f(x) = ax mod N is invisible in the time domain — but in the frequency domain, the period r becomes a sharp, measurable peak.

This is what Shor recognized in 1994: the problem of factoring can be reduced to the problem of finding a period — and quantum computers are uniquely equipped to do that.

MEASURE → FACTORS → KEY EXPOSED
Measurement collapses the state to a peak. Classical GCDs extract p and q. The private key follows immediately.
// Step 5: Measure — wave collapses to a peak frequency // (Example: small N = 3,233 = 61 × 53, a = 2) MEASURE m = 21,845 // integer at frequency peak // continued fraction algorithm recovers period r from measurement m CONT-FRACr = 6 // m=21,845 → continued fraction → r=6 // Classical GCD gives the prime factors GCD(+) gcd(2³ + 1, 3233) = 61 = p GCD(−) gcd(2³ − 1, 3233) = 53 = q // Verify VERIFY 61 × 53 = 3,233 = N ✓ ⚠ RSA PRIVATE KEY: DERIVED // "derived" = attacker can now decrypt all past & future traffic encrypted with this key
COMPLEXITY RECAP
The algorithm is probabilistic — it may require a handful of repetitions to get a usable measurement (the math says at most O(log log N) — a very small number even for huge N). Even so, the total run time remains O((log N)³) — polynomial.
THE GAP
300 TRILLION YEARS
→ HOURS TO DAYS
RSA-2048 classically: ~300 trillion years on the fastest supercomputer.

RSA-2048 on a CRQC (Cryptographically Relevant Quantum Computer — a machine large enough and stable enough to run Shor’s at scale): hours to days. Same lock. Same key. An entirely different class of attacker.

No key size offers refuge — 4096-bit, 8192-bit, any size. Shor's attacks the structure, not the length.
