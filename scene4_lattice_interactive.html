THE REQUIREMENT
Any replacement must be hard for both classical and quantum computers — not just one. We need a mathematically different kind of hard problem.
The Hard Problem: Shortest Vector Problem (SVP)
Lattice = integer combinations of basis vectors
SVP: find shortest non-zero vector in lattice NP-Hard
Best classical algorithm (BKZ) 2O(n)
Best quantum algorithm (QSVP) 2O(n)
KEY INSIGHT
Shor's algorithm exploits periodicity — lattice problems have no such structure to exploit. Quantum computers gain no significant speedup over classical attacks on well-chosen lattice parameters.
LEARNING WITH ERRORS (LWE)
In practice, PQC uses LWE: given a noisy linear system, recover the secret. The noise destroys periodicity. Even with a quantum computer, solving LWE requires exponential time.

How PQC Standards Replace RSA / ECDH
KEY EXCHANGE RSA / ECDH → KYBER-768
SIGNATURE RSA-PSS / ECDSA → DILITHIUM-3
HASH SIG RSA-PSS variant → SPHINCS+
All four are FIPS-approved as of Aug 2024.
Three are lattice-based · One is hash-based.
SPHINCS+ (amber) — hash-based fallback. Conservative security assumptions with no lattice dependency. Larger signatures and slower than Dilithium-3. Prefer ML-DSA for performance-sensitive deployments.
All four are FIPS-approved standards (Aug 2024). Google, Cloudflare, Apple, and AWS have begun deploying Kyber in production. Most enterprise migrations haven't started.

THE MIGRATION CLOCK
2024
NIST PQC Standards Finalized
Kyber, Dilithium, FALCON, SPHINCS+ become FIPS 203–206. The math is done. The clock starts now.
2025–2027
Early Adopter Phase
Browsers, cloud providers, and hyperscalers deploy hybrid PQC. Most enterprise infrastructure untouched.
2027–2030
Compliance Mandates Arrive
CISA, NSA, and NIST mandate PQC for federal systems. Financial and healthcare regulators follow. Migration backlogs build.
2030+
Legacy Systems Become a Liability
Any long-lived data encrypted today with RSA/ECC is now retroactively readable — if it was harvested. Cyber insurers begin excluding quantum risk.
est. 2033–2035

Mainstream intelligence estimates. At this point, unpatched systems are immediately vulnerable. Harvested data — collected years earlier — decrypts.
